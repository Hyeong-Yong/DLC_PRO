# 튜닝 계수 교정 · 데모 모드 · LongTerm 기본 단위 — 2026-10-01

## 1. 스캔 스펙트럼으로 튜닝 계수 교정

위치: **Scan & Lock → MHz 축 탭 → "Laser N 튜닝 계수 교정"** 카드. 레이저마다 따로 있으며, 결과도 레이저별 설정 파일에 저장됩니다(`settings.ini`, `settings-laser2.ini`).

### 사용 순서

1. 스캔을 켜고 스펙트럼이 보이면 그래프 위의 **[스캔 CSV 저장]**을 누릅니다. X축은 MHz 표시와 관계없이 피에조 전압(V) 그대로 저장되고, 형식은 DLC pro 내보내기와 같은 `"Piezo Voltage (V)";"Fine In 1 (V)";`입니다.
2. **전이**를 고릅니다.
   - **Cs D2 852 nm · 6S1/2 F=4 → 6P3/2 F'=3,4,5**: F'=5–F'=4 간격(251.09 MHz)과 F'=5–F'=3 간격(452.38 MHz)으로 계수를 각각 계산합니다. 전이 3개와 교차 공명 3개, 모두 6개 선으로 선 배정을 합니다.
   - **Cs 1470 nm · 6P3/2 → 7S1/2 F''=3,4**: 7S1/2 초미세 분리 F''=4–F''=3 간격(2183.48 MHz)을 씁니다. 같은 중간 준위(F'=4)에서 나오는 두 선이라 도플러 이동이 같아서, 간격이 그대로 보입니다.
3. **[CSV 불러와 교정]**을 누릅니다. **[현재 스캔으로 교정]**을 누르면 파일 없이 지금 그래프로 바로 계산합니다.
4. 결과:
   - **SUCCESS**: 계수가 위쪽 **튜닝 계수 입력란에 자동으로 들어가고** 저장됩니다. 프로그램을 꺼도 유지됩니다. 교정 시각, 전이, 파일 이름도 함께 기록합니다.
   - **FAIL**: 오류 대화상자와 로그에 사유를 보여 주고, 계수는 **바꾸지 않습니다**.

### 계산 방법 (`Core/Calibration/TuningCalibrator.cs`)

1. 선 모양은 흡수형과 분산형 Lorentzian을 섞은 형태, 배경은 4차 다항식으로 둡니다. 선 패턴 전체(x0, 계수, 폭)를 격자 탐색한 뒤 Levenberg–Marquardt로 맞춰서 어느 선이 어느 전이인지 정합니다. 시작 계수(200–800 MHz/V)나 주파수 방향이 달라도 같은 결과가 나옵니다.
2. 선마다 중심과 폭을 따로 풀어 정확한 중심 전압과 그 오차를 구합니다.
3. 튜닝 계수 = 이론 간격 ÷ 측정 전압 간격. 간격이 두 개이면 두 값의 평균을 씁니다. 부호는 전압을 올릴 때 주파수가 올라가면 +입니다.
4. 판정 기준 (모두 통과해야 SUCCESS)

| 항목 | 기준 | 의미 |
|---|---|---|
| 간격 일치 | 두 간격에서 구한 계수 차이 ≤ 3 % (카드에서 바꿀 수 있음) | 이론 비율과 맞는지 확인. 선 배정이 틀리거나 피에조가 비선형이면 커짐 |
| 선 위치 잔차 | 6개 선 모두 이론 패턴 대비 ≤ 10 MHz rms | D2 선택지에만 적용 |
| **분산형 우세** | 0 V 기준 양/음 신호 대칭도 ≥ 0.15 | 편광 분광의 분산형 신호는 0 V 양쪽으로 흔들림. 신호가 한쪽 극성에만 있으면 흡수형이 우세하다고 보고 FAIL |
| 계수 범위 | 현재 계수 × 0.35 ~ 3 안쪽 | 탐색 범위 경계에 걸리면 선 배정 실패로 판단 |

   대칭도가 0.5보다 낮거나, 기준선(F'=5)이 0 V를 지나는 점이 공명에서 멀면 SUCCESS여도 경고를 함께 보여 줍니다.
5. 측정 데이터(2026-09-30) 결과:
   - **PS_D2 line2 → FAIL**: 계수 차이 4.7 %, 대칭도 0.00(신호 전체가 음수, 흡수형 우세).
   - **PS_D2 line3 → SUCCESS**: 329.6 MHz/V. F'=5–F'=4는 328.2, F'=5–F'=3은 331.0 MHz/V로 차이 0.86 %입니다. 경고 두 가지: 대칭도 0.21, F'=5의 0 V 교차점이 +36.5 MHz.
6. 6P3/2 → 7S1/2는 선이 2개뿐이라 간격끼리 비교할 수 없고, 주파수 방향도 스펙트럼만으로는 알 수 없습니다. 방향은 "주파수 방향"을 따로 고르지 않으면 현재 계수의 부호를 따릅니다. 결과 그래프에서 선 배정을 꼭 확인해 주세요.
7. 새 전이를 추가하려면 `Core/Calibration/CalibrationPresets.cs`에 선 목록과 간격을 넣고 `All`에 등록하면 됩니다.

### 기본값

- 튜닝 계수 기본값은 **0.328 GHz/V (328 MHz/V)**입니다. 설정 파일이 없거나(초기화) 값이 0이면 이 값을 씁니다. 레이저 1·2 모두 같습니다.

## 2. 데모 모드 (하드웨어 없이 제어 UI 확인)

- 연결 막대 둘째 줄의 **[데모 연결 (가상 장비)]**을 누르거나, `dotnet run --project DLC_PRO.csproj -- --demo`로 실행합니다.
- 앱 안에서 레이저 2대짜리 가상 DLC pro를 띄우고, **루프백(127.0.0.1)의 빈 포트**로 연결합니다. 실제 장비나 네트워크에는 접속하지 않고, IP/포트 설정도 저장하지 않습니다.
- 상단에 **DEMO · 가상 장비** 배지가 뜨고, 창 제목에 `[DEMO]`가 붙습니다.
- Laser 1 "TA852 (DEMO)": Cs D2 F=4 편광 분광 스펙트럼 (328 MHz/V).
- Laser 2 "TA1470 (DEMO)": 6P3/2 → 7S1/2 스펙트럼 (328 MHz/V).
- 데모에서는 모든 제어 화면(Laser, Scan & Lock, ReLock, Stabilization, Wide Scan, Recorder, System, Console, Settings)을 쓸 수 있습니다. 튜닝 계수 교정도 그대로 해 볼 수 있습니다.
- **연결 해제**를 누르면 가상 장비가 꺼집니다.
- **주의**: 데모에서 교정하거나 설정을 바꾸면 레이저별 설정 파일에 그대로 저장됩니다(실제 사용과 같은 파일). 데모로 확인한 뒤에는 실제 장비에서 다시 교정해 주세요.
- 시뮬레이터 코드는 `Tests/Simulator.cs`에서 `Core/Demo/DlcSimulator.cs`로 옮겼습니다. 회귀 테스트도 같은 코드를 씁니다.

## 3. WLM LongTerm graph 기본 단위

- LongTerm 창의 단위 기본값을 **Wavelength, vac. [nm]**로 바꿨습니다.
- 예전 설정 파일에 저장돼 있던 "WLM 표시 단위 따름"은 예전 기본값이었으므로 한 번 Wavelength, vac.으로 바꿉니다. 이후에 사용자가 직접 고른 값은 유지합니다(`wavemeter.ini`의 `Version=2`).
